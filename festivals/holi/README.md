# Holi Greeting Page for Google Blogger

Mobile-first personalized greeting card generator for Holi 2026.

## Files
- `config.json`: Festival dates, colors, metadata, and wish pool.
- `index.template.html`: Source template.
- `blogger-post.html`: Generated single-file code ready to paste into Blogger.

## Build
```bash
node build/build.js --festival holi
```
